# Application source map

The CLI and server compose the same domain services. Tests mirror those domains; integration runners verify installed
artifacts and complete browser workflows. Source paths below are relative to `app/`.

- [Records and workflows](source-maps/records.md): Record contracts, task authority, planning, and review.
- [Collections](source-maps/collections.md): Record collections.
- [Distribution](source-maps/distribution.md): Distribution and updates.
- [Execution](source-maps/execution.md): Checks and environments.
- [Acquisition](source-maps/acquisition.md): Tool acquisition and dependencies.
- [CLI and configuration](source-maps/interfaces.md): Commands, terminal presentation, and shared settings.
- [Browser interface](source-maps/web.md): Workflow views, scoped navigation, live publication, and browser
  verification.
- [References](source-maps/references.md): Examples and quality support.
