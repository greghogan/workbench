# Examples and quality support

- `scripts/managed-inputs.mts`, `scripts/managed-inputs.mjs`: Derives standalone managed check inputs, Guix crate
  origins, and React runtime inventories from dependency locks.
- `scripts/python-checks.mts`, `scripts/python-checks.mjs`: Runs frozen Python checks and installs the exported locked
  graph from declared local wheels in managed environments.
- `scripts/package-managed.mts`, `scripts/package-managed.mjs`, `scripts/verify-managed.mts`,
  `scripts/verify-managed.mjs`: Prepare example Nix closures and Guix portable packs and verify their behavior in
  isolated containers.

- `scripts/values.mts`, `scripts/values.mjs`: Validates shared helper input shapes and required values.
- `scripts/vendor-types.d.mts`: Declares the used upstream coverage API where the package omits types.

- `tests/tsconfig.json`: Checks test fixtures against their test-runtime APIs while the root TypeScript project
  separately checks the application baseline.
- `tests/fixtures/installations.mts`, `tests/fixtures/review-interaction.mts`: Share per-test fixture setup and cleanup
  across isolated installation and review suites while keeping writable state and mocks local to each suite.
